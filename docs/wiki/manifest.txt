# Wiki publish manifest — read by scripts/publish-wiki.sh
#
# One entry per line:   <source path from repo root> | <wiki page name>
#
# The page name becomes the filename and the page title. Hyphens render as
# spaces, so `Architecture-Overview` publishes as "Architecture Overview" at
# /wiki/Architecture-Overview. Keep names flat — the wiki has no folders.
#
# A missing source file fails the publish. An empty one is skipped with a
# warning, so a placeholder doc can sit in the manifest until it is written.
